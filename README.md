# OpenAuto Multimedia

Мультимедиа-приложение для обычной Android-магнитолы: сенсорный плеер и собственный беспроводной приёмник Android Auto. USB для подключения телефона не используется.

**Статус:** сборка для проверки на устройствах. Протокол и TLS проверяются локальными тестами; совместимость с конкретной магнитолой и телефоном пока не подтверждена. Полная работа зависит от Bluetooth/Wi-Fi и аудиосистемы прошивки.

## Установка
Собрать в Android Studio задачу `:mobile:assembleDebug`.
APK: `mobile/build/outputs/apk/debug/mobile-debug.apk`.
Передать файл на магнитолу по сети или с накопителя и установить. Минимальная версия приложения — Android 9 (API 28); целевое устройство пользователя — примерно Android 14.

Модуль `:mobile` предназначен для обычной магнитолы. Отдельный `:automotive` предназначен для AAOS и не нужен для этого сценария.

## Bluetooth-музыка
1. Сопрячь телефон через штатное Bluetooth-приложение магнитолы и включи музыку.
2. В OpenAuto выбери Bluetooth.
3. Нажми «Источник», разреши управление медиасессиями через системный доступ к уведомлениям и выбери Bluetooth-плеер.
4. Обложка, трек и сенсорные команды доступны, если штатный Bluetooth-сервис предоставляет метаданные и управление.
5. Громкость закреплена внизу экрана. Главный экран не прокручивается; настройка соединений открывается кнопкой «Подключение».

Если источник не появился, нужен интерфейс Bluetooth от производителя этой прошивки. Сам мост к медиасессиям не реализует A2DP-приёмник. На устройствах с отдельным MCU-усилителем системная громкость также может потребовать OEM-адаптера.

## Android Auto без проводов
1. Выбери Android Auto → «Подключить телефон» и предоставь запрошенные разрешения.
2. Приложение создаст Wi-Fi Direct-сеть и запустит Bluetooth-настройку соединения.
3. «Сопрячь телефон» включает системный запрос видимости магнитолы. Выбери магнитолу на телефоне и начни беспроводное подключение в Android Auto.
4. При первом TLS-соединении подтверди сертификат своего телефона. После подтверждения соединение запускается повторно.
5. Для голосового ввода отдельно разреши микрофон. Он записывает только по запросу телефона во время открытого экрана проекции.
6. В экране проекции доступны касания, системная громкость и выход. Звонки используют настоящее штатное подключение громкой связи.
7. Если соединение прервано, нажми «Подключить». Уход из экрана в фон завершает сеанс.

Встроены H.264-видео, PCM-звук, сенсорный ввод и микрофон. Их работу с физическим оборудованием ещё нужно проверить. Не все китайские магнитолы предоставляют приложениям стандартный Bluetooth RFCOMM: отдельный Bluetooth-модуль требует адаптера производителя.

Для разработки оставлен раскрываемый раздел диагностики с подключением по IP к серверу Android Auto на телефоне. Обычный беспроводной сценарий этого сервера не требует.
